# Security Policy

## Supported versions

The latest release and `main` receive security fixes.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/wowlabdev/eslint-config/security/advisories) or the [WoW Lab contact page](https://wowlab.gg/contact). Do not open a public issue.

## What to include

- Where the issue is.
- How to reproduce it.
- Its impact.

## Scope

This repository and the published `@wowlab/eslint-config` package are in scope. Test only against systems and data you own.

## Safe harbor

Good-faith research under this policy will not draw legal action. Report issues privately and allow time for a fix.
